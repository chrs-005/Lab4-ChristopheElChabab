# Lab 4 - School Management System

This project contains Tkinter and PyQt5 interfaces for the school management system. Both interfaces use the same SQLite database backend.

## Run the Tkinter interface

```bash
python part2_tkinter.py
```

## Run the PyQt5 interface

Install PyQt5 if it is not already installed:

```bash
pip install PyQt5
```

Then run:

```bash
python part3_pyqt5.py
```

The Tkinter interface uses Python's built-in Tkinter library. The PyQt interface uses PyQt5. Both interfaces allow users to manage students, instructors, courses, registrations, and assignments through the shared database code in `part4_database.py`.
